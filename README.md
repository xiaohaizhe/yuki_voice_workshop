# AI 语音工作台

这是将豆包与 MiniMax 合并后的本地网页语音工具，适合不懂代码的使用者。

当前版本为 v0.1.11，界面已调整为更明显的手绘游戏任务板风格，并在页面顶部显示版本标识；启动器会自动避开已被旧版本占用的端口。

## 第一次启动

1. 确认电脑已经安装 Python 3.11 或更高版本。
2. 双击 `RUN_AI_VOICE_STUDIO.cmd`。
3. 第一次启动会联网安装运行组件，时间可能需要几分钟。
4. 浏览器自动打开 `http://127.0.0.1:8765`。

如果双击 BAT 没有反应：

1. 确认已经将 ZIP 完整解压，不要在压缩包预览窗口中直接运行。
2. 双击 `备用启动AI语音工作台.cmd`。
3. 启动器会停留并显示步骤；失败时会在当前文件夹生成 `startup_log.txt`。
4. 如果 Windows 显示安全提示，请先核对文件来源，再选择允许运行。

## 日常使用

- “单条生成”：适合反复调整某一条语音。
- “批量生成”：下载 Excel 模板，填写后导入；可以逐条试听、重新生成，并选择部分或全部音频打包下载。
- 表格里的音色、情绪、语气指令、语速和音量都可留空；留空时使用网页上方的整批默认值。
- 网页批量表格里的音色、情绪、语速和音量均提供下拉选项；Excel 模板也内置对应下拉，减少手填出错。
- 批量表格里的“语音文字”会先显示两行预览，点击文字区域可展开长句，避免长语句把页面撑乱。
- MiniMax 默认音量已从原始 `1.0` 调整为推荐 `2.0`；如果声音过大，可以在页面或表格中改回 `1.0`。
- 情绪选项会在后台转换为 MiniMax 可接受的参数；豆包当前音色会忽略情绪字段，避免真实接口返回 `invalid params`。
- 右上角“接口配置”中可以新增或删除声音 ID。新增后会自动进入单条生成和批量生成的音色下拉。

## 接口配置

首次打开默认使用“模拟模式”，不会调用接口，也不会产生费用。确认页面流程无误后：

1. 点击右上角“接口配置”。
2. 填写同事提供的豆包 App ID、Access Token 和/或 MiniMax API Key。
3. 取消勾选“使用模拟模式”。
4. 保存后先用短句进行一次单条测试。

凭证保存在当前文件夹的 `config.local.json`，不会写进源码。请不要把这个文件发给其他人；如需转交工具，先删除它。

如果看到“没有这个复刻音色权限”，通常是 API Key 所属账号没有对应 Voice ID，不是页面参数问题。

## 情绪和音量参数说明

- MiniMax：当前工具会把页面里的中文情绪转换成 MiniMax 接口可接受的英文枚举；音量使用 MiniMax 支持的 `vol` 参数。
- 豆包：当前接入的 `seed-tts-1.0` 路径没有稳定开放“情绪”和“音量”字段。为了避免接口报 `invalid params`，工具不会把这两个字段强行传给豆包；豆包主要支持语速等基础参数。
- 如果 MiniMax 返回 `you don't have access to this vc`，通常不是情绪或音量导致，而是当前 API Key 没有该 Voice ID 的权限。
- 如果页面显示 `0:00 / 0:00` 或浏览器无法播放，通常说明接口虽然返回了数据，但这段数据不是有效音频。v0.1.10 会在保存前检查 MP3/WAV 头部，无法播放的结果会直接标为失败，不再显示“生成成功”。

## 安全说明

- 服务仅监听本机 `127.0.0.1`，同一局域网的其他人无法访问。
- HTTPS 证书校验保持开启。
- 日志不打印输入文案、完整密钥或完整请求头。
- `data/audio` 保存本次生成的音频，可在确认下载后手动清理。
