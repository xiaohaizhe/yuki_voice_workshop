# AI 语音工作台

把豆包与 MiniMax 两家语音接口合在一起的本地网页工具，面向不懂代码的同事：输入文字或导入表格，就能生成、试听、打包下载语音，也能复刻声音。

- **作者**：yuki
- **当前版本**：v0.1.14
- **性质**：团队内部工具，版权归作者所有，未开放许可。

## 第一次启动

1. 确认电脑已经安装 Python 3.11 或更高版本。
2. 双击 `RUN_AI_VOICE_STUDIO.cmd`（或 `启动AI语音工作台.bat`）。
3. 第一次启动会联网安装运行组件，可能需要几分钟。
4. 浏览器会自动打开工作台，默认地址是 `http://127.0.0.1:8765`；这个端口被占用时，启动器会自动换到 8766～8775 中空闲的一个。

如果双击没有反应：

1. 确认已经将 ZIP 完整解压，不要在压缩包预览窗口中直接运行。
2. 双击 `备用启动AI语音工作台.cmd`。
3. 启动器会停留并显示步骤；失败时会在当前文件夹生成 `startup_log.txt`。
4. 如果 Windows 显示安全提示，请先核对文件来源，再选择允许运行。

## 功能一览

### 单条任务

适合反复调整某一条语音。

- 填写文字，选择音色、语速、音量、情绪、语气指令，点“生成语音”，可试听和下载。
- **试听**：音色下拉旁的“试听”按钮会用一句固定短句合成，方便快速听出这个音色是什么声音。
- **高级参数**（点击展开，仅对 MiniMax 音色生效）：
  1. 语调与精细调节：自定义语速、自定义音量、语调。
  2. 语言与文本处理：语种增强、数字与日期读法、发音词典。
  3. 停顿与语气词：点一下，把停顿标记或语气词插入到文字的光标处。
  4. 音频输出与效果器：文件格式、采样率、比特率、音色效果器、特殊音效。
- 每个参数旁的“?”悬浮可看说明；区域底部有一段“使用说明”。
- 不展开、不填写高级参数时，生成结果与以前的版本完全一致。选中豆包音色时这一区会置灰。

### 批量任务

- 下载 Excel 模板，填写后导入；可以逐条试听、重新生成，并选择部分或全部音频打包下载。
- 表格里的音色、情绪、语气指令、语速和音量都可留空；留空时使用网页上方的整批默认值。
- 网页表格和 Excel 模板里的音色、情绪、语速、音量都提供下拉选项，减少手填出错。
- “语音文字”先显示两行预览，点击可展开长句。
- 高级参数目前只在“单条任务”生效，批量任务不受影响。

### 声音复刻

- 上传同一个人的多段清晰录音，工具会按选择顺序合并（合计 10 秒～5 分钟），提交给 MiniMax 或豆包复刻。成功后新音色会自动出现在音色下拉里。
- **素材预检**：选好录音后，先在本机显示合并时长、可试听合并结果，并提示时长不够、底噪偏高、停顿太少、爆音等问题。这一步不上传、不计费。
- **高级选项**（点击展开，仅对 MiniMax 生效）：降噪和音量归一化开关、自定义 voice_id、复刻后立即试听、示例音频增强相似度。
- 豆包使用已开通的“复刻 2.0”预付费音色槽位（`S_` 开头的音色 ID），重新训练会覆盖该音色。

复刻前请注意：

- **只能复刻本人或已取得本人明确授权的声音。** 提交前需要勾选授权确认。
- 素材会上传至所选服务商，可能产生费用。
- MiniMax：复刻本身不扣费，音色第一次用于合成时扣 9.9 元；复刻后 7 天内没有正式合成过会被系统删除。
- “复刻后立即试听”会产生费用：试听文字按合成价计费，并触发该音色的首次使用费。

### 其他

- MiniMax 默认音量已从原始 `1.0` 调整为推荐 `2.0`；如果声音过大，可以在页面或表格中改回 `1.0`。
- 右上角“接口配置”中可以新增或删除声音 ID，新增后会进入单条和批量的音色下拉。

## 接口配置

首次打开默认使用“模拟模式”，不会调用接口，也不会产生费用（生成的是一段提示音）。确认页面流程无误后：

1. 点击右上角“接口配置”。
2. 填写同事提供的豆包 App ID、Access Token 和/或 MiniMax API Key。使用豆包复刻还需要填写豆包 API Key（新版）。
3. 取消勾选“使用模拟模式”。
4. 保存后先用短句进行一次单条测试。

凭证保存在当前文件夹的 `config.local.json`，不会写进源码，也不会被提交到 Git。请不要把这个文件发给其他人；如需转交工具，先删除它。

## 情绪和音量参数说明

- 情绪选项：开心、兴奋、惊讶、悲伤、愤怒、焦急、害怕、厌恶、平静、温柔、严肃。
- MiniMax：工具会把页面里的中文情绪转换成 MiniMax 接口可接受的英文枚举；音量使用 MiniMax 的 `vol` 参数。
- 豆包：当前接入的 `seed-tts-1.0` 路径没有稳定开放“情绪”和“音量”字段。为了避免接口报 `invalid params`，工具不会把这两个字段传给豆包；豆包主要支持语速等基础参数。

## 常见问题

- **“没有这个复刻音色权限” / `you don't have access to this vc`**：通常是 API Key 所属账号没有对应 Voice ID，不是页面参数问题。
- **页面显示 `0:00 / 0:00` 或无法播放**：说明接口返回的数据不是有效音频。工具会在保存前检查音频头部，无法播放的结果会直接标为失败，不会显示“生成成功”。
- **读错数字、人名、缩写**：在单条任务的高级参数里选“高质量归一化”，仍读错再用发音词典。
- **复刻后的声音句尾有气声或怪音**：多半是素材问题（连着说话、没有停顿，或底噪高），换参数很难消除，请参考复刻区的“使用说明”重新录素材。

## 安全说明

- 服务仅监听本机 `127.0.0.1`，同一局域网的其他人无法访问。
- HTTPS 证书校验保持开启。
- 日志不打印输入文案、完整密钥或完整请求头。
- `data/audio` 保存本次生成的音频，可在确认下载后手动清理。
